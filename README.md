# 映格 · 电影学习素材标注

Windows 桌面客户端。双击 `start.cmd` 启动，或运行 `python app.py "工程文件夹"`。主流程为抽取电影画面、标注人物与台词、人工确认和导出训练素材。已有检测权重可辅助画框或跟踪人物。

## 抽取画面

点击「导入电影」。未打开工程时，数据保存在当前用户主目录下的 `映格工程/默认工程`。也可先点「打开工程」指定文件夹。影片原文件只读。

可先用 5 秒一格粗采全片，再指定起点和终点，用 1 秒或 0.25 秒一格补采对话、反应等片段。每次填写期望新增数，客户端在所选范围内分段随机取样，返回实际新增数。同一工程以电影文件内容摘要识别影片，移动或改名后可续采。每次写入都会检查本片实际画面时间码和保存图片的 SHA-256 内容摘要，命中任一项即跳过。静止画面的不同时间点也可能因此只保留一张。近似但有变化的画面可以分别保留。旧工程在首次续采时为原有图片补建索引，并保留原标注。

多部电影可在首次导入时分别指定「整部训练」或「整部验证」，使验证集包含未见电影。单部电影可按片内时段分组，后续各层沿用首次选择。

## 人物、物件和台词

1. 选择「人物」或添加物件类别。在空白处拖动画框，在框内直接拖动可移动，拖角点可缩放。Shift 加拖动可在已有框内创建重叠框。
2. 双击人物框，或选中后点「人物名与台词」。填写本片角色名或从已有名字选择，每行输入一句此人说的台词。无对白的听者只填姓名。多个人同框时分别标注。保存后，角色名显示在框上。
3. 台词与该人物框一起保存；移动、缩放及撤销均保留对应关系。删除框会一并删除其绑定，可用「撤销」恢复。每次编辑自动保存草稿，点「确认图片并继续」后纳入素材包。
4. 需要机器先画框时，点「辅助识别」。它读取已有权重，为未标注的训练图片生成草稿，由人工补框或更正后确认。

## 字幕与画外发言

导入电影抽帧时会自动索引内嵌文字字幕，以及电影同目录下同名或带语言后缀的 SRT、VTT、ASS、SSA，例如 `电影.zh.srt`。已有工程可点「字幕 → 提取 / 更新电影字幕」重新选择原片，单独补提字幕。各语言轨分别保存。「字幕 → 导出字幕为 SRT」可将指定的文字轨另存。

双击人物框后，「当前画面字幕候选」列出覆盖该画面时间的字幕行。选中一行，点「采用所选字幕」，确认角色后保存。仅将你采用的行归给该角色。烧录到画面上的字幕可点击「识别画面底部字幕」，使用本机 Windows OCR 读取当前图底部 45% 的区域；可以修正文字再保存。OCR 依赖已安装的系统识别语言。只有音频的对白可手填。

说话人没有出现在画面里时，选图后直接点「画外台词 / 旁白 → 新增发言」。选择「画外人物」「旁白」或「来源未确定」，角色名可留空。这里同样可以采用字幕或手填，同一帧可添加多条不同来源的发言。只拍到听者时，可单独给听者的框命名。这些发言支持编辑、删除和撤销，无框画面也可直接确认。

## 连续片段与角色轨迹

「分析片段」可选择电影、起点及最长 120 秒的连续时段，每秒采样 4 次。「角色确认」提供轨迹的首帧、代表帧和末帧裁剪。可以将相似衣着的候选排在一起，勾选同一角色的多条轨迹后命名，也可撤回或更名。这些角色名在本片的单帧标注对话框内可供复用。

## 导出给电影学习模型

点击「导出学习素材」生成可移动的 ZIP。压缩包中包含：

- `frames/` 存放已确认的原始抽帧图片。
- `samples.jsonl` 每行对应一张已确认画面，按电影及实际时间排序。含电影名称和内容摘要、`time_ms`、`sample_interval_ms`、训练或验证分组、图片相对路径以及画面对象。各对象含类别、归一化坐标 `bbox_xyxy`、片内角色名 `character` 和逐句台词 `dialogue`；`object_id` 只在该行画面内标识对象。
- `tracks.jsonl` 每行是一条经人工命名的轨迹，含同一电影摘要、片内角色名、片段、估计镜头编号和采样点。各点依次为毫秒、左、上、右、下，坐标按画面归一化。
- `subtitles.jsonl` 保存工程中已索引的电影文字字幕时间轴，含电影摘要、来源轨、原文及毫秒起止时间。字幕轨本身不含人工确认的说话人归属。

每帧的 `frame_dialogue` 保存无框发言，包含来源类型、可为空的角色名及台词。已采用并保留原文的字幕用 `subtitle_refs` 记录来源和字幕显示时间；OCR 只记录采样画面时间。手填或改写的台词按人工标注保存。字幕显示时间可能与实际开口、停声时间有出入。训练切镜时机或反应节奏时，仍需连续镜头和实际切点。

## 环境与兼容性

新机器安装带 Tk 的 Python 3.11+，执行 `python -m pip install -r requirements.txt`。Windows PyAV 二进制包自带解码库。已用短视频验证 MP4、M4V、MKV、MOV、AVI、WebM、TS、M2TS、MPG、WMV、FLV 和裸 H.264。权重默认可使用 `weights/yolo11n.pt`。工程数据在 `annotations.sqlite` 与 `frames/`，备份时复制整个工程目录。
